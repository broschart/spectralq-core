OpenStreetMap Changes

Monitors OpenStreetMap edits in the defined region over the last 30 days, tracking newly drawn or modified roads, buildings, military infrastructure, airports and other map features.

How to use: Draw a zone on the map and click "Live". All changes are listed with the mapper's username, edit date, object type (new vs. modified) and version history. Click on an entry to see the exact location on the map.

Forensic relevance: While crowdsourced, OSM edits are forensically relevant when local mappers document changes on the ground — new military checkpoints, destroyed bridges, refugee camps or road closures. Coordinated editing activity by new accounts can also indicate information operations.

Data source: OpenStreetMap / Overpass API — no API key required.
Draw observation areas on the map. OSM changes from the last 30 days will be fetched automatically.
