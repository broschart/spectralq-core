Wayback Archiving Frequency

Analyses how often a URL has been cached by the Internet Archive over time, revealing patterns in archiving frequency.

How to use: Add a URL and click "Live". The system queries the Wayback Machine CDX API and shows the total number of snapshots, the first and last archive dates, daily average frequency and peak archiving periods.

Forensic relevance: High archiving frequency can indicate media attention, coordinated access campaigns or deliberate preservation efforts. A sudden spike in archiving may point to viral content, controversy or anticipated takedowns. Comparing archiving frequency before and after events helps quantify public interest and media impact.

Data source: Wayback Machine CDX API — no API key required.
Enter URLs and create a zone. Archiving frequency will be fetched automatically from the Wayback Machine CDX index.
