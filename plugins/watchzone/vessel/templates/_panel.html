Vessel Tracking

Monitors vessel movements via AIS (Automatic Identification System) within a user-drawn maritime area.

How to use: Draw a zone on the map, then click "Live". The view lists all vessels in the area with name, type, flag state, heading, speed and destination in real time.

Anomaly detection: Unusual behaviour — such as unexpected stops, course deviations or dark periods (AIS switched off) — is automatically flagged. This helps identify smuggling routes, sanctions evasion or illegal fishing activity.

Data source: VesselFinder / AISHub — no API key required.
Draw rectangles or polygons on the map to define maritime areas. VesselFinder data shows vessel movements in real time.
