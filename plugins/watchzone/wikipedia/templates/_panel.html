Wikipedia Monitoring

Tracks edits and page views of specific Wikipedia articles over time.

How to use: Add a Wikipedia article URL and click "Live". The system shows the edit count and timeline over the last 30 days, page size changes, and an author analysis including account age. Use parallel coordinates to filter by edit size, author or date.

Forensic relevance: Wikipedia articles about conflicts, political figures or organisations are often edited in coordinated campaigns. Sudden spikes in edit activity — especially by new accounts — can indicate information operations. Page view surges correlate with media events and public attention. Tracking who edits what and when provides insight into narrative control attempts.

Data source: Wikipedia / Wikimedia API — no API key required.
Add Wikipedia articles whose changes should be monitored. The article search uses the Wikipedia Search API for exact matches.
