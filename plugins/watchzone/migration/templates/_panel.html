Displacement & Migration

Monitors refugee populations, asylum applications and internally displaced persons (IDPs) based on official UNHCR statistics.

How to use: Draw a zone covering one or more countries and click "Live". The system shows current refugee and IDP counts per country, plus a 10-year trend analysis that reveals long-term displacement patterns.

Forensic relevance: Migration data can be correlated with conflict events (ACLED), search volume spikes and media coverage to build a comprehensive picture of crisis dynamics. Sudden increases in displacement figures often precede or confirm escalation phases. Comparing origin and destination countries helps trace displacement corridors.

Data source: UNHCR Refugee Statistics API — no API key required.
Draw observation areas on the map. UNHCR data will be fetched automatically for the respective countries.
