Global Zones

Global zones apply simultaneously to all observation categories. Once drawn, the zone automatically appears in every active category – ideal for a permanent observation area you don’t want to define multiple times.

Time Focus: Assign an event (Time Focus) to a global zone via the zone menu (··· → Time Focus). All plugins that collect data for this zone will automatically align their analysis around the event date – showing data before, during and after the event for comparative analysis.

Data Collection ("Sammeln"): Click the “Sammeln” button on a global zone to collect data from multiple plugins simultaneously. Configure plugin-specific parameters (e.g. countries for Internet Health, commodities, Telegram search terms), then collect all data in one step. Results are displayed in a comprehensive overview with maps, charts, images and tables – and automatically saved for later review. Use the history button to recall the last collection without re-fetching.

Typical workflow:
  1. Draw a global zone on the map (rectangle or polygon)
  2. Name it and optionally assign a Time Focus event
  3. Click “Sammeln” → select and configure plugins → collect
  4. Review the aggregated results across all data sources
  5. Use “Live öffnen” on individual plugin cards for deep analysis
